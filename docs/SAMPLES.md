# Sample Datasets of molass_data and molass_benchmarks

Reference for the test datasets included in the `molass_data` package (`SAMPLE1`-`SAMPLE5`) and in the
`molass_benchmarks` package (data of known composition).

## Overview

| Dataset | Protein(s) | Frames | q-points | q range (1/Å) | Expected Rank | Notes |
|---------|-----------|--------|----------|---------------|---------------|-------|
| SAMPLE1 | ALD + OA | 242 | 1028 | 0.006 – 0.437 | 2 | Two-component standard mixture |
| SAMPLE2 | (unknown) | 1000 | 783 | — | — | Very hard case |
| SAMPLE3 | GI | 360 | 775 | 0.0075 – 0.4192 | 2 | Interparticle effects (SCD ≈ 5.14) |
| SAMPLE4 | **simulated** | 220 | 773 | 0.0073 – 0.4075 | 3 | Three overlapping species with a small Rg drop (molass_data 0.6.0 and later) |
| SAMPLE5 | BSA | — | — | — | — | Measured; minor components |

| FOLDUNFOLD_DISCRETE (`molass_benchmarks`) | **simulated** | 220 | 773 | 0.0073 – 0.4075 | 3 | Three discrete fold/unfold species, Rg 48 / 33 / 22 Å |

## Detailed Descriptions

### SAMPLE1 — Aldolase + Ovalbumin

- **Species**: ALD (aldolase, ~158 kDa) + OA (ovalbumin, ~44 kDa)
- **M shape**: 1028 × 242
- **Known issue**: One row of all-zero errors in the error matrix (requires floor correction)
- **Use case**: Standard two-component benchmark; well-separated peaks

### SAMPLE2

- **M shape**: 783 × 1000
- **Use case**: Stress test (very hard case); details undocumented

### SAMPLE3 — Glucose Isomerase

- **Species**: GI (glucose isomerase, ~173 kDa tetramer)
- **M shape**: 775 × 360
- **q range**: 0.0075 – 0.4192 Å⁻¹
- **UV file**: 720 columns (2:1 ratio vs SAXS frames; see [FORMAT.md](FORMAT.md))
- **UV peak frame**: ~200
- **SCD**: ≈ 5.137 (above `RANK2_SCD_LIMIT = 5.0`)
- **Expected rank**: 2 (due to interparticle interference, not multiple species)
- **Rg (rank-1)**: ~27.6 Å (biased by c² term)
- **Rg (rank-2)**: ~33.4 Å (closer to true value)
- **Use case**: Demonstrates interparticle effect detection and rank-2 correction

### SAMPLE4 — simulated (since molass_data 0.6.0)

- **M shape**: 773 × 220
- **Truth**: three overlapping species at frames 81 / 95 / 115 (areas 47 / 33 / 20 %), each a folded core (sphere, R = 27 Å) with a disordered Gaussian-chain tail (Rg 18 Å) of different mass share; true Rg 28.6 / 26.7 / 25.1 Å (Guinier fits come out about 6 % lower). Generated by `molass.Testing.simulate_sample4_like("tails3")` (`molass_data/scripts/make_tutorial_data4.py`; form factors after Pedersen 1997).
- **Geometry and noise**: those of the measured data set it replaces (which was removed from the public package): same q grid, frame count, stated error and actual scatter.
- **Use case**: overlapping components without a prominent peak; how many components are justified. The truth is available in `ssd.simulation_truth` when the data are regenerated.
- **Note**: up to molass_data 0.5.0 SAMPLE4 was a measured data set; results from those versions differ.

### SAMPLE5 — bovine serum albumin

- Measured; minor components (see the Molass Library paper); details undocumented here.

## `molass_benchmarks`

Data of known composition, kept out of `molass_data` to keep that package small.

- **`PROTEINS5`**: measured mixture of five proteins (`20191006_proteins5`); formerly `SAMPLE6` of `molass_data` 0.5.0. Used by the library's peak-matching test (mapping of five peaks).
- **`FOLDUNFOLD_CONTINUUM`**: simulated; fast-exchange mix of a folded sphere and an unfolded Gaussian chain whose unfolded fraction falls along the elution; one peak with a trailing shoulder (`simulate_sample4_like("fold_unfold_continuum")`).
- **`FOLDUNFOLD_DISCRETE`**: simulated control; three discrete fold/unfold species (`simulate_sample4_like("fold_unfold_discrete")`); `get_continuity_report()` reports it as `discrete`.

```python
from molass_benchmarks import PROTEINS5, FOLDUNFOLD_CONTINUUM, FOLDUNFOLD_DISCRETE
```

## Usage

```python
from molass_data import SAMPLE1
from molass.DataObjects import SecSaxsData as SSD

ssd = SSD(SAMPLE1)
M = ssd.xr_data.M      # SAXS matrix (n_q × n_frames)
q = ssd.xr_data.qv     # q-vector
E = ssd.xr_data.E      # error matrix
```

See also [FORMAT.md](FORMAT.md) for the raw file format details.
